- C/P60：Host 恰一身份已执行，Schema 缺互斥。canonical ID 没有统一格式正则；Host 以真实 locator 存在性与 scope 判定，不编造格式契约。
- C/P64：get_schema 真实 Schema 只有空 properties；必须验证额外参数拒绝，不能假定签名无参数就安全迁移。
- C/P66/D/P67：Host 解析 cursor 字段并核对范围/filters，Schema 是宽 object；没有跨轮 cursor 去重 guard，“never repeat”仍由模型负责。
- D/P39/P63：SQLite read-only connection、authorizer、单语句、scope 查询边界和 max_rows 有 deterministic enforcement；SQL error stopping 与 unknown schema choice 没有机械承接。
- E：source resolution/当前 run/provenance 与 shape 已确定性执行，但局部 graceful finalization 可以 degraded。作者、时序、reply/recommendation、穷尽负面不是 Finalizer 验证能力。
