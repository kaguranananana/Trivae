# 产品预览的运行条件

README 截图于 2026-10-19 从实际运行的 Vue Web UI 拍摄，使用现有真实群聊数据库、FastAPI 服务、Application、Router、Runtime、检索工具、Finalizer 与会话持久化。截图中的结果来自实际模型请求，没有合成聊天消息、伪造回答或改写页面内容。

## 数据与环境

- 查询限定在用户已有的一个技术交流群，不使用全部群聊范围。
- 使用现有 `deepseek / deepseek-flash` 主模型和现有检索索引，没有为截图修改生产业务代码或模型返回。
- 在浏览器中正常选择聊天范围、发送问题与多轮追问。服务仅绑定回环地址。
- 技术方案表格是实际多轮会话的最后一次回答；Skills 图使用独立会话直接提问并返回结果。折叠状态与滚动位置仅用于选择展示画面。

## 展示的问题

### 近期 Skills

直接提问：

> 最近群里有哪些好用的 Skills？挑三个，每个用一句话介绍用途，附上项目链接，不用写人名。

截图展示实际返回的用途说明和公开仓库链接。提问没有指定检索工具、关键词、数据库字段或预设答案。

### 近期技术讨论与方案

初始问题：

> 最近两天群里都在讨论哪些技术？有没有值得试试的方案？

为了便于阅读与分享，继续追问：

> 只保留技术方案，用简短要点说明解决什么问题、怎么尝试，不写群友姓名和无关话题。

> 挑三个最值得试的方案，用表格列出方案、用途和第一步，不用长篇介绍。

截图展示最后一轮实际生成的方案、用途与第一步表格，左侧保留原始会话标题。初始长回答中的成员昵称及无关话题未纳入展示画面。

## 隐私与结论边界

图片展示技术主题与公开项目链接，未展开原始消息 Sources、群成员昵称、QQ 账号、文件路径或凭据。完整聊天数据库、会话导出、原始 Trace 与模型请求均未加入本轮文档提交。

结果仅代表当前群聊、检索窗口和运行配置下的一次实际输出。回答保留检索覆盖与资料完整度限制；群内对工具和方案的评价不等于独立效果验证。本次预览不用于声明答案准确率或性能提升。
