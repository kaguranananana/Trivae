## 归档约定

- 后续生成的项目导学、项目面经、面试题库、STAR 口播、简历事实摘要和 Claim 核验材料均放在本目录。
- 文件名应直接体现用途与项目，例如 `导学-Trivae.md`、`面经-Trivae.md`。
- 新增、删除或重命名文档时，同步更新“当前文档”索引。
- 面试文档只引用可核验的仓库事实；未确认的个人职责、指标、上线结果与业务效果必须标记为待确认或待测。
