# 面试文档

本目录统一存放与 Trivae 项目求职和面试准备有关的文档，避免与产品源码、Trellis 任务材料及 Evaluation 运行产物混放。

## 当前文档

- `导学-Trivae.md`：前置知识、源码阅读顺序、核心原理、设计决策与验证建议。
- `面经-Trivae.md`：简历 bullet、STAR 口播、主问题、追问及源码证据索引。
- `简历-Trivae-Agent岗.md`：在原稿结构上做事实边界与可读性轻量修正的五条项目经历，可直接用于 Agent 岗简历。
- `证据复盘-Trivae.md`：按交付阶段、个人动作、效果证据和责任边界整理的九段证据链。
- `Trivae-Claim证据账本.json`：供简历、面经及后续模板复用的结构化主张—证据账本。

## 归档约定

- 后续生成的项目导学、项目面经、面试题库、STAR 口播、简历事实摘要和 Claim 核验材料均放在本目录。
- 文件名应直接体现用途与项目，例如 `导学-Trivae.md`、`面经-Trivae.md`。
- 新增、删除或重命名文档时，同步更新“当前文档”索引。
- 面试文档只引用可核验的仓库事实；未确认的个人职责、指标、上线结果与业务效果必须标记为待确认或待测。
