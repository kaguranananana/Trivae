# 面试反问技巧：群聊证据整理

> 2026-10-23，长消息分页修复后的真实自主回答。原问题：“关于面试中的反问，有提到过哪些技巧吗”。仅概括本次实际读取证据，区分真人面经与机器人建议，不声称穷尽群内全部历史。

有，提到的不只是“准备几个问题”，而是把反问用来获取反馈、核实岗位、判断团队是否适合自己。比较实用的内容可以整理成下面几类。

1. 让面试官帮你复盘，正反两面都问。JoyeBot 和“奶龙大学副校长”都建议直接问：“我今天哪里表现得不好、需要改进？”以及“我哪里做得还不错？”目的不是自己猜面试结果，而是拿到具体反馈。日音小摩卡的实际反问清单里也有：“您对我有什么建议吗？不管是面试简历还是个人表现。”Bot 还建议把反馈和面试记录结合，面三五场后找反复出现的薄弱点。

2. 别停在 JD 上，追问实际要做什么、做到什么程度。joye 提到自己会问：“这个岗位的具体要求是什么，希望有什么能力，会遇到什么挑战？”因为官网 JD 信息不足。更具体的问法还有：“入职后第一个要上手的项目是什么？”“如果 3 个月内，你希望我或团队达到什么样的里程碑成果？”前端岗位则有人问：“偏全栈还是主要做前端？”“目前有哪些比较强的需求？”对 prompt/Agent 岗，Bot 补充过：“日常主要是写 prompt，还是搭评估体系？”这些问题都是把岗位描述落到真实任务、职责边界和产出预期。

3. 问团队的真实工作方式，不只问一句“氛围好吗”。joye 的面经列过：工作节奏和考核方式、业务及产品方向、开发排期、技术/产品/设计的人员配比、正式员工与实习生比例、团队技术氛围、AI Native 程度。还有更具体的切口：“你日常是怎么和 AI 进行高效协作的？”“你是怎么和 AI 协作的，某个工具具体哪里好用？”“奶龙大学校长”另外提出过一道反问题：“AI 对于你们公司来说是什么？”这些可以用来了解对方实际怎么工作，而不只是听抽象介绍。

4. 面初创时，按“产品—老板—钱—赛道和竞品”做判断。joye 给过一套很完整的清单：
• 产品：产品与市场的匹配程度（PMF）、准确上线时间、产品与研发人员比例，以及自己是否对赛道感兴趣。
• 老板与早期团队：背景、创业或其他突出经历，聊下来是否合拍、是不是一类人。
• 钱：资金来自融资还是老板的其他公司；融资金额、国内或国外资金、投资机构背景。
• 赛道和竞品：joye 随后专门补充不能漏掉这一项。
此外还有具体工作内容、期望产出、工资、技术氛围和 AI Native 程度。回首空城也提过应该多问对方的想法，并分享自己曾加入一家只有大想法、缺少具体实现路径的初创的经历。

5. 技术反问要贴着对方产品问，落到难点和取舍。日音小摩卡的清单很具体：“主要产品有哪些，攻克的技术难点有哪些？”“模型是端侧还是云端？”“记忆有什么特别优化，现在采用什么记忆范式？”“评测和数据链路追踪有没有人在深入做？”还提出过产品设想：是否考虑结合时间日志，根据用户正在干什么推断其任务。这类问题的特点是顺着对方业务继续深入，而不是泛泛问用了什么技术栈。

6. 如果是冲转正的日常实习，要问清名额和工作含金量。JoyeBot 建议向业务主管核实，而不是只问 HR：“咱们组今年的校招 HC 还有余量吗，或者往年日常实习生走春招补录转正的比例大概多少？”以及“进去后是跟着正式员工做主线业务，比如核心 Agent 链路/数据底座，还是做外围工具支持？”它提醒不要把“看表现、向公司申请”自动理解为有转正机会。这里有用的技巧是把模糊承诺拆成名额、历史比例、具体任务来问；不过 Bot 原文中“回答含糊就大概率没坑位”“明确留人就立刻接”等判断较绝对，不能仅凭一句回答决定去留。

另外，群里也出现过“让面试官现场演示一下”“反过来让面试官做题”这类调侃式反问。其中“让面试官做题”当时有人明确说还没试过，所以不要把这些与上面的实际面经、反馈问法混为一谈，更不能当成已验证有效的技巧。
