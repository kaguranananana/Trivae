# 面试反问技巧：群聊证据整理

> 2026-10-23。原问题：“关于面试中的反问，有提到过哪些技巧吗”。以下为修复后同题真实自主回答正文，保留真人分享与机器人建议的区别；仅概括本次已读取证据，不声称穷尽群内全部历史。

有，群里提到的反问不只是“最后随便问两句”，主要是拿反馈、核实岗位，以及判断团队是否适合自己。可以整理成下面这几类；其中既有群友面经里的实际问法，也有 bot 给出的建议。

1. 直接请面试官帮你复盘，优点和不足都问。群里的 bot 多次建议问：“我今天哪里表现不好、需要改进？”以及“我哪里做得还不错？”目的不是自己猜挂在哪，而是拿到具体反馈。日音小摩卡贴的面经里也实际列了：“您对我有什么建议吗？不管是面试简历还是个人表现。”

2. 把模糊的 JD 问成具体工作和交付预期。Joye 说自己问过：“这个岗位的具体要求是什么，希望有什么能力，会遇到什么挑战？”因为官网 JD 写得太空。更具体的问法还有：“入职后第一个要上手的项目是什么？”以及日音小摩卡面经中的“如果 3 个月内，你希望我或团队达到什么样的里程碑成果？”bot 还建议，面 Prompt/Agent 岗时可以问：“这个岗位日常主要是写 prompt 还是搭评估体系？”这些问题分别帮助核实能力要求、实际工作和岗位深度。

3. 问团队如何运转，不只问“氛围好不好”。Joye 的面经里有一套较完整的清单：具体工作节奏和考核方式；业务/产品方向及开发排期；技术、产品、设计的人员配比；正式员工与实习生的比例；团队 AI Native 程度和技术氛围。他也把“具体工作内容、期望工作产出、工资”列入反问范围。可以理解为同时摸清工作要求、人员支持和待遇，而不是只听一句笼统介绍。

4. 面初创时，按“产品—老板—钱—赛道与竞品”做尽调。Joye 提到的细项包括：产品有没有找到 PMF、准确上线时间、产品与研发人员比例，以及自己是否对赛道感兴趣；老板和早期成员背景、创业或其他经历、聊下来是否合拍；资金来自融资还是老板其他公司，融资金额、境内外来源及投资机构背景；另补充要看赛道和竞品。回首空城也建议多反问对方的想法，并分享自己曾加入一家只有大想法、没有具体实现路径的初创，做下去才发现希望不大。这里的重点是问清实际进展和实现路径，不只听愿景。

5. 技术反问尽量落到具体做法，也可以顺便学习。Joye 的实际问法有：“你日常是怎么和 AI 进行高效协作的？”奶龙大学校长还提过“AI 对于你们公司来说是什么”，以及追问某个工具具体哪里好用。日音小摩卡的清单更贴近业务：当前有哪些产品、正在攻克哪些技术难点；是否考虑结合时间日志来推断用户行为；模型在端侧还是云端；记忆采用什么范式、做了什么优化；评测和数据链路追踪有没有人在深入做。总结起来，就是从抽象标签追问到场景、方案和实际投入。

6. 如果是为了转正去实习，要明确问坑位和是否参与主线业务。JoyeBot 给过两句很具体的问法：“咱们组今年的校招 HC 还有余量吗，或者往年日常实习生走春招补录转正的比例大概多少？”以及“我进去之后是跟着正式员工做主线业务，还是做外围工具支持？”它建议问业务主管，而不只问 HR，目的是避免进去后一直做边缘工作，却没有转正机会。它还把“看表现、向公司申请”当作需要警惕的模糊答复；但这只能作为风险线索，不能单凭一句话断定没有坑位。

另外，群里也出现过比较冲的反问：面对“Claude Code/Codex 一句 prompt 就能做出你的项目”，有人说让面试官现场共享屏幕演示，或反问他们公司的产品是否也能一句 prompt 做出来；还有人提过让面试官做题。但这些只能算群聊里的提议，并没有有效性证据，其中“让面试官做题”当时还有人明确说自己没试过，不宜当作成熟技巧直接照搬。
