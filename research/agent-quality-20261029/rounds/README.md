# Z Code R1历史脚本归档

2026-10-31按用户要求，将最近研究成果提交并同步到研究分支。此目录保留Z Code在2026-10-30中断前产生的R1脚本，七份可共享脚本原文纳入版本控制，没有修改其实现或重新执行实验。

| 脚本 | 原用途 |
|---|---|
| R1_replay.py | 重放旧64 Run的词法、语义查询，生成逐调用和逐事实分析 |
| R1_postprocess_proj.py | 将旧工具结果与模型可见投影交叉分析 |
| R1_q2_s3_drill.py | 细分原S3候选到消息的断层 |
| R1_q5_token.py | 探索性Token估计与运行Usage对比 |
| R1_q7_omitted.py | 汇总Trace中的消息省略 |
| R1_q8_temporal.py | 汇总时间和范围错误诊断 |
| R1_q9_behavior.py | 对比原Prompt A/B的检索行为 |

这些是带时间边界的分析快照，使用原本机路径，部分依赖当时的临时semantic clone及ignored实验数据，不是当前正式评测入口。不要在当前源码上直接执行并覆盖旧输出。正式评测继续使用EvaluationWorkspace；当前固定候选池对照和实验证据入口见上级[REPORT.md](../REPORT.md)与[STATE.md](../STATE.md)。

后续已校正的口径：原数值ID区间判断可能误报；来源ID相交不等于语义事实采用；Q5的1.31不是精确tokenizer校准；实际64/64首轮模型输入已有查询时间。旧Q8只查看Prompt得出的推断不能作为当前缺陷。原脚本保留用于追溯，不将其探索性结果作为已验证的最终结论。

以下原件原位保留，仅本机可见，不随Git推送：

- `outputs/`内十一份JSON，包含原始检索结果、消息正文或私有实验明细；没有删除、移动或改写。
- `scripts/R1_q4_adjudication.py`，直接内嵌群聊原句和逐条裁决。其13/14一致是模型辅助复核，不是人工一致率。
- 上级`.request-meter.lock`，仅用于并发计数器互斥。

接管后已核验的汇总结果、负结果、预算和失败边界均在上级研究报告及账本中。克隆仓库可以阅读方法和结论，但不包含完整私有语料与原始运行数据。
